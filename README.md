# NovaEPG

Guía de Programación Electrónica (EPG) para NovaPlay.

## 🌐 Interfaz Web
Puedes acceder al buscador de canales e IDs en:
[https://novaplaytv.github.io/novaepg/](https://novaplaytv.github.io/novaepg/)

## 📺 Datos para la App
- **XMLTV GZ (Recomendado):** `https://raw.githubusercontent.com/novaplaytv/novaepg/main/epg/guide.xml.gz`
- **XMLTV Plano:** `https://raw.githubusercontent.com/novaplaytv/novaepg/main/epg/guide.xml`

- **TVMAX** (Local)
